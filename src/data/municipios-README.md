# Coordenadas municipais

`municipios.json`: nome, UF, latitude e longitude das sedes municipais.
Fonte: https://github.com/kelvins/municipios-brasileiros
Revisão: 503e2f70bbf1b4b7ec0b1f68b09086ccc38fe861 (csv/municipios.csv).
Licença MIT preservada em municipios-LICENSE.txt.

Usado apenas no build, não enviado inteiro ao navegador. Os pontos representam
as cidades, não o local exato de um evento ou uma rota percorrida. Lugares sem
correspondência inequívoca ficam na lista e não recebem coordenadas inventadas.
