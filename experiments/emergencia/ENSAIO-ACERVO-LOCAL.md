# Ensaio do acervo local — não é restauração completa

Usuário relatou conferência real: 50 registros em sete tabelas, ZIP com 81 arquivos / 34.256.257 bytes; 49 referências reconhecidas presentes, zero ausentes/externas/não classificadas. 32 arquivos sem referência preservados. JSON e ZIP guardados pelo usuário. Datas fornecidas no relatório são metadados das capturas, não confirmação da data atual. Nenhum binário real foi solicitado ao chat.

Entrega: entregas/ensaio-recuperacao-local.html, gerado por scripts/gerar-ensaio-local.mjs. Abre JSON + ZIP localmente e reconstrói acervo em memória: cadastros como texto (details/pre), arquivos como prévias blob para JPEG/PNG/WebP identificados por assinatura. SVG/HTML/formatos desconhecidos não renderizados. Não interpreta HTML do cadastro. CSP bloqueia conexões, objetos e formulários; img-src somente blob. Nenhum storage persistente, dependência remota, SQL, upload ou escrita. Botão limpar/pagehide revoga URLs e remove conteúdo; seletores de arquivo ainda podem reter seleção até fechar aba. Usar computador confiável, não publicar arquivos privados.

Validação: pacote editorial, estrutura ZIP, CRC e SHA256 antes de montar acervo. Contadores de candidatos a imagem não comprovam decodificação; eventos reais de load/error mostram contadores separados e lazy loading exige rolar a página. Arquivos permanecem originais no ZIP. Isto não extrai para disco nem restaura Supabase, esquema, RLS, Auth, Edge Functions, URLs ou layout do site. Não representa teste de navegação do site inteiro ou recuperação de desastre concluída.

Teste tests/ensaio-local.mjs usa somente fixtures: igualdade de JSON/bytes, ZIP inválido, detecção de tipo, cadastro malicioso exibido como texto, URL blob e limpeza. JSDOM não decodifica imagens reais: load simulado testa contador, não renderização. Suíte test:emergencia regenera os dois HTMLs e roda testes. Suíte completa passou localmente com Node 22.23.4. Nenhum deploy nesta etapa.
